# Blocker assessment
Gather live ticket and repository facts. Cite authority and explain the next action.
Assess choice risk separately from ticket merge risk. Preapproved reversible wording can be safe on a medium-risk ticket.
Never downgrade delivery risk or change merge authority. Follow human/cite_only/bounded mode.
Escalate conflicting instructions, unsupported options, protected changes, or uncertain authority.
Return the structured triage result; a proposed answer requires the configured deterministic validator.

Include `reason` explaining how the cited authority supports this exact choice, its scope, and reversibility. Missing rationale must not be filled in by the caller when policy requires it.
